## Print settings

| Parameter                    | Value                     | Comment                           |
| ---------------------------- | ------------------------- | --------------------------------- |
| Nozzle diameter              | 0.4 mm                    |                                   |
| Layer height                 | 0.2 mm                    |                                   |
| Wall loops                   | 6                         | ⬈ Strength                        |
| Order of walls               | Inner/outer/inner         | ⬈ Dimensional accuracy & ⬊ Seam   |
| Infill density               | 25%                       |                                   |
| Infill pattern               | Cubic                     |                                   |
| Support                      | Tree                      |                                   |
| Support/object 1st layer gap | 0.35 mm                   | Avoid support & part merging      |

| Glue                         | Liquid or 3DLAC           |                                   |
| Filament material            | ASA (Flashforge or Bambu) |                                   |
